# SigMarker 使用指南

[返回 README](../README.md)

## 打开与调整图片

将文件拖入整个文档预览区，或点空白区中央的打开按钮，也可通过 **文件 → 打开…** 或 `Ctrl+O` 选择文件。支持 PNG、JPEG、BMP、TIFF、HEIC/HEIF 和 PDF；PDF 当前读取第 1 页。

空白画布中央并排提供本地打开和手机扫码导入。`Ctrl+V` 可导入剪贴板中的图片或复制的本地文件；剪贴板图片在内存中处理，透明区域按白纸读取，不生成临时原图。输入参数时，`Ctrl+V` 仍用于粘贴数值。

图片按 EXIF 修正方向，HEIC 使用主图及容器方向。自动检测会尝试将竖排笔迹旋转为横排；方向不合适时，可用画布右上角的工具条顺时针或逆时针旋转 90°，当前裁剪框随图片旋转，保留已选范围。自动框选和关闭文件也位于此工具条。

自动范围使用背景亮度校正、可信墨迹筛选、连通笔画聚组和桌沿过滤，减少弱纸纹和阴影噪声造成的选框扩张。不需要重新画框，直接拖动现有裁剪框及其手柄即可调整。检测不区分姓名、日期和印刷正文，复杂内容需要手动裁剪。

深灰与白底预览保持相同缩放：左侧检查白边和透明边缘，右侧看盖在白纸上的效果。底色仅用于预览，文件名只在顶部文件栏显示。

## 笔迹参数

纸色与光照校正始终自动执行，无需开启开关；加载设置时会清理旧版记住的关闭状态。

| 参数 | 适用情况 |
| --- | --- |
| 淡墨保留 | 笔画缺失、细笔画断裂时逐步增大；过大可能带入纸纹或噪点。 |
| 对比度 | 调整保留下来的笔迹明暗表现。 |
| 墨迹浓度 | 去背景后加深已保留的笔画，范围 1.00～3.00×，默认 1.00×，自动记忆。 |
| 不透明度 | 控制最终水印整体透明度，在其他处理后应用。 |
| 锐利度 | 手机照片笔迹偏糊时适度调整，不能恢复原图中不存在的细节。 |
| 墨色 | 选择黑色、白色或原始墨色。 |
| 清除孤立噪点 | 去除远离笔迹的细小污点；请同时检查需要保留的细笔画。 |

处理淡墨时，先确认笔迹被保留下来，再提高浓度。默认浓度不改变原有提取结果，浓度调整也不改变墨色和像素尺寸。

五项参数的滑条等长，右侧数值框可直接键入；按回车或离开输入框后应用，滑条、预览和记忆值同步更新。“恢复默认”位于参数栏右上角。

## 复制、导出与 DPI

右侧“导出 DPI”统一控制剪贴板、PNG、PDF 和图章的物理尺寸。默认 **300 DPI**，下拉提供 **100 / 150 / 200 / 300 / 600 / 1200** 预设，也可直接输入 **72～1200**，按回车或离开输入框后应用并记忆。无效或越界输入在失焦时恢复上次有效值。状态栏右侧显示像素、毫米尺寸和 DPI，改变 DPI 不重采样。

例如宽 476 px 的签名：在 300 DPI 时约 40.3 mm，在 600 DPI 时约 20.2 mm。

- **复制透明签名**：Windows 同时提供带透明度和 DPI 的 PNG、CF_DIBV5 数据；接收软件最终采用的格式和缩放仍以实际粘贴结果为准。
- **导出透明 PNG**：适合粘贴到支持透明图片的文档或图片编辑器。
- **导出 PDF**：使用透明蒙版，并按所选 DPI 写入物理尺寸。

右侧底部先提供整行的“复制透明签名”，PNG 与 PDF 并排，图章导入单独一行。手机照片与剪贴板图片的导出默认目录为用户图片目录，无法取得时使用用户主目录；不会默认保存到接收照片的临时目录。

## 手机导入与网络排查

电脑点击“手机扫码导入…”后才启动服务。多网卡环境可选择手机能访问的 WLAN 或以太网地址，避免误选代理或虚拟网卡。启动直接使用 IP 绑定，不进行反向 DNS 查询。

手机浏览器提供系统拍照与相册入口，不需要安装 App。相机入口的具体表现由浏览器决定，仍可从相册选择已拍照片；HEIC 上传不依赖浏览器能否预览原图。

### 会话与原图

- 二维码包含随机访问令牌，有效 10 分钟，只接收一张有效照片。无效照片可在有效期内重选并重试。
- 关闭窗口、会话过期、成功接收后停止服务。切换地址或刷新二维码后，旧链接失效。
- 每张最多 30 MiB、6000 万像素，按实际文件内容检查，不依赖扩展名或 MIME 声明。
- 电脑没有文件时自动载入；已有文件时先预览，点“使用此照片”才替换，点“放弃”保留当前文件。
- 手机显示“电脑已接收”仅表示接收完成，电脑端可能仍在等待确认。
- 原始照片临时保存，放弃、关闭对应文件、成功替换或退出时清理，不自动长期留存。需要的签名请在退出前导出。

服务只监听选定 IPv4 和临时端口，不提供本地文件浏览或下载，不自动修改防火墙或建立公网映射。HTTP 未加密，令牌只控制访问；请在可信局域网使用，不要转发会话链接。

### 连接不上时

1. 确认所选地址属于手机可访问的 WLAN 或以太网接口；网络变化后刷新二维码。
2. Windows 询问是否允许通信时，只在可信的专用网络放行。
3. 检查公司无线网络是否隔离客户端，手机与电脑是否分属不同 VLAN 或网段。
4. 检查 VPN/代理是否改变访问局域网的路由。
5. 扫码应用无法打开时，将完整链接复制到手机系统浏览器。

页面完全打不开时，请先在电脑对话框查看排查提示；工具无法自动判断具体网络隔离原因。手机与电脑不必连接相同名称的 Wi-Fi，但必须能够互访。

实机记录：用户于 2026-10-22 在三星 S20U（安卓）确认微信或相机软件扫码、直接拍照上传及 HEIC 上传正常。其他设备与浏览器仍需分别验收。

## 添加到 PDF-XChange 图章

点击右侧“添加到 PDF-XChange 图章…”，选择现有图章集合，填写图章名称后导入，无需先导出独立 PDF。首次使用请核对默认位置或浏览选择；成功后记住所选路径。

导入会保留已有页面、名称登记及元数据，在集合所在目录的 `SigMarker-backups/` 保存原文件副本（`.pdf.bak`，不会作为图章加载），验证通过并完成备份后才原子替换。普通 PDF 不会被当作集合覆盖，受保护或加密的集合不支持修改，所在目录需允许当前用户写入。

工具允许运行中尝试导入，不按 PDF-XChange 进程是否存在主动拦截，也不会自动启动或关闭它。实际文件锁定、无写入权限或集合并发变更时停止，保留原文件。当前用户环境曾确认 PDF-XChange 运行时会锁定集合，需要退出以释放锁定。

“已写入集合”不代表图章面板已刷新。导入后检查面板，未出现时可尝试重新打开面板或重启 PDF-XChange。

格式与加载行为参考：[厂商集合格式说明](https://forum.pdf-xchange.com/viewtopic.php?t=19555)、[集合文件锁定](https://forum.pdf-xchange.com/viewtopic.php?p=175349)、[重启加载集合](https://forum.pdf-xchange.com/viewtopic.php?f=62&t=36122)。

## 窗口与快捷键

`Ctrl+O` 打开文件，`Ctrl+V` 粘贴图片或文件，`Ctrl+W` 关闭当前文件，`Ctrl+Q` 退出。顶部“关于”菜单提供软件介绍和 GitHub 仓库入口。

关闭文件后保留软件与参数，可以继续打开或拖入新文件。关闭软件时记住窗口尺寸、最大化状态及上下预览区比例，下次启动恢复。

关于窗口显示 V0.1.0 版本和开源许可证，点击“复制诊断信息”可复制版本、系统、Python 和 Qt 信息，用于手动反馈；不包含当前文档、个人路径、网络地址或扫码令牌，不会自动发送。

错误日志保存在 `%LOCALAPPDATA%\SigMarker\logs\sigmarker.log`，最多保留两个轮转备份，每个约 512 KiB。仅记录错误类型和程序内部位置，不记录异常正文、签名图像和文件路径。日志可删除，不影响设置和导出文件。便携包目录内提供完整许可证及第三方版权声明。
